## Текущий результат

Этапы 0–5 и локальная часть этапа 6 реализованы. Публикация в Telegram отложена по просьбе пользователя. Полный цикл из 27 этажей работает с настоящими GLB: отдельные база, A/B/C/special, кран, крыша и камерная зимняя диорама. Масса главного здания создана build-time генератором, окружение адаптировано из конкретных лицензированных CC0 Kenney-пакетов. PBR/environment локальные; окна инстансированы, снег — Points в трёх слоях, надпись 2027 — Text3D.

Проверены физический проход до 27 этажей, промах/повтор, production сборка и glTF validation. Крыша и 2027 уже подготовлены и показываются при завершении. Теперь финал проходит по config timeline: камера → крыша → окна/2027 → Bloom/снег/confetti → экран завершения. Pause/replay и reduced motion проверены. После cinematic показывается карточка с одним из десяти стабильных пожеланий. Работают Radix share dialog, копирование текста, экспорт PNG и replay. Telegram text/link flow подготовлен, фактическая отправка не выполнялась. Проверены адаптивные размеры, все тексты на 320×568, две high партии и low/static партия; GPU resources возвращаются к исходному plateau. Последние проверки и остающиеся задачи публикации — docs/VERIFICATION_LOCAL_RELEASE.md и docs/LOCAL_RELEASE.md.

## Архитектура

`pointer / keyboard → game commands → Zustand → presentation`

`Rapier collision / crossing plane → collision.ts → game events → Zustand`

- `src/game`: чистые правила попадания, конфиги, типы и единственный store приложения. Здесь нет Three.js и Rapier.
- `src/physics`: активное тело Rapier, контакт, падение при промахе. Только верхняя опора имеет fixed collider; уже установленные этажи — обычные meshes.
- `src/scene`: Canvas, камера Drei, башня, кран, презентация объектов. Кадровое положение swing локально, результат и жизненный цикл — в store.
- `src/ui/ida`: DOM-компоненты, бренд-токены, Motion и Radix primitives. UI не обращается к Rapier.
- `src/telegram`: SDK, user, viewport, safe areas, lifecycle, back и haptic. Обычный браузер работает без fake Telegram user.
- `src/audio`: два Howl на всё время приложения, original CC0 assets, загрузка по interaction, pause/mute, без нового audio pool при replay.
- `src/assets`: локальные пути, паттерн этажей и декодирование quantized geometry для instancing. `src/effects`: отдельный clock и семантические фазы кинофинала, lazy composer и confetti cleanup.

## Инварианты

1. Один активный этаж; повторный tap во время падения не создаёт новое тело.
2. `overlap >= 0.9`: perfect; `overlap >= 0.45`: success; иначе fail. Пороговые значения в gameConfig.ts.
3. Perfect выравнивается по центру верхней опоры. Success сохраняет фактическое смещение.
4. Неуспех увеличивает только mistakes; башня сохраняется. Новый этаж появляется спустя 750 мс.
5. Старые этажи не участвуют в динамической симуляции.
6. Для полного промаха без контакта учитывается пересечение высоты опоры — этаж продолжает физическое падение.
7. Уход приложения в фон ставит физику и swing на паузу. Отложенные переходы не добавляют этажи в новую сессию.
8. Telegram launch data используется для персонализации, не как доверенная авторизация. Backend не требуется.
9. Sound toggle работает и сохраняет preference; audio не создаётся до первого interaction.
10. Не выдаём browser-тест за проверку настоящих Telegram iOS/Android.

## Художественное направление

Premium architectural diorama: светлый бетон, тёмное стекло, графитовый металл, тёплый свет. Праздник через свет, снег и атмосферу. Основное устройство — portrait smartphone; desktop сохраняет игровую область 480–600 px. Палитра временная, согласовано пользователем 28.09.2026; перед финальным бренд-ревью нужны точные цвет/шрифт/логотип либо утверждение этих токенов.

## Внешние материалы до выпуска

- Фирменные логотип, цвет и корпоративный шрифт, либо утверждение временных токенов.

- Утверждение текстов пожеланий.
- Реальные устройства для измерения FPS и финальной приёмки.
