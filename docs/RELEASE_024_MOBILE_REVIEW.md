## Причина снижения качества

Раньше ширина до 700 px вместе с coarse pointer автоматически выбирала mobile GLB. Геометрия у профилей одинаковая, но атласы отличались:

| Атлас | Раньше на телефоне | Теперь по обычному адресу, как на десктопе |
| --- | --- | --- |
| Участок | 2048 × 2048 | 4096 × 4096 |
| Этаж | 1024 × 1024 | 2048 × 2048 |
| Снег, венок | 512 × 512 | 1024 × 1024 |

Общий размер пяти GLB: 4.66 → 6.83 MB. Никакие модели, цвета и запечённый свет не пересоздавались. Убрано определение качества по типу указателя. По обычному адресу high и DPR 3, ограниченные бюджетом 5 млн пикселей; автоматическое снижение отключено. В проверочном окне 390 × 844 буфер 1170 × 2532. Явные диагностические профили остаются: `?quality=auto` — полные атласы и адаптивный DPR; `?quality=mobile` — облегчённые атласы.

## Проверка

Пройдено:

- `node node_modules/vitest/vitest.mjs run`: 101 тест, 20 файлов. Регрессии покрывают default high, плотные мобильные экраны, лимит буфера, ручную/фоновую паузу, DPR 3 открытки и освобождение контекста с учётом StrictMode. Существующие тесты проверяют 15 этажей, три жизни, устаревшие события, баланс, Rapier-обрушение в обе стороны без стартового импульса вверх, выбор открыток, звуки и голографию.
- `node node_modules/typescript/bin/tsc -b`, production build и Pages build с `/ida-light-2027/`.
- Браузер: три физических промаха → новый раунд; два прохода по 15 физических точных посадок через видимые dev-кнопки → paper-tree, затем reindeer. Ручное переключение карточек для этого не использовалось.
- Браузер: пять последовательных однонаправленных посадок со смещением → обрушение и новый раунд. Подробная траектория без подпрыгивания проверена автоматическими физическими тестами; покадровая видеозапись этого прохода не делалась.
- Браузер: пауза блокирует Space, продолжение возвращает игру; в production Enter на старте переводит фокус к сбросу. Стрелки наклоняют открытку, Escape возвращает её в исходное положение.
- Сохранённый в браузере PNG paper-tree побайтно совпадает с исходником: SHA-256 `96d1eb6d0bc39593cc67fe661ccbbb9006a0b6d654447c9d559ce60d04f80156`.
- На 320 × 568 обе финальные кнопки: x=16, width=288, height=48; открытка внутри экрана, горизонтального скролла нет. На 390 × 844 цели pause/sound 44 × 44; поля 20 px. На desktop поля 32 px.
- Контраст вычислен из CSS-пар: белый/#245bf3 5.43:1; #1a1b1d/#efefef 14.99:1; #1a1b1d/белый 17.24:1. Контур подписи поверх самого светлого стопа неба #afcfde даёт композит #64757e и 4.79:1.
- В консоли браузера нет ошибок приложения. Остаётся предупреждение deprecated initialization внутри установленной Rapier dependency; оно не прерывает игру. Vendor-файлы не патчились. Предупреждение Vite о крупном Three/Rapier chunk также остаётся.

**Not verified:** реальные iOS/Android и Telegram WebView, touch/pinch на физическом устройстве, Safari download sheet, VoiceOver/NVDA, forced-colors, настоящий browser zoom 200%, аппаратная потеря WebGL и медленная сеть. Loading/error/reduced-motion проверены по исходным веткам и соответствующим тестам, без принудительного сбоя GPU. Размеры мобильного экрана проверены в браузере компьютера; это не замер FPS телефона. Полные атласы занимают около 117 MiB с mipmaps, поэтому одинаковые ассеты не означают одинаковую частоту кадров на любой аппаратуре.

## Verdict

**Approve** в пределах указанного потока и браузерной проверки. Подтверждённые HIGH-находки исправлены. Непроверенные платформы перечислены отдельно; отсутствие вообще всех возможных ошибок не заявляется.
