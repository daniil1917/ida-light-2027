# Смена открытки после повторной победы · 0.23.1

20 октября 2026.

Причина: в 0.23.0 выбор сохранялся навсегда для браузера, а в Telegram вычислялся из ID пользователя. Новая открытка присутствовала в сборке, но повторное прохождение не меняло назначенный вариант.

Теперь каждая успешно завершённая башня выбирает открытку заново среди вариантов, кроме предыдущего. При двух открытках они чередуются; когда каталог расширится, следующий вариант будет случайным из оставшихся. Последний результат запоминается между визитами, а при недоступном localStorage — в памяти приложения. Старые сохранённые ключи учитываются как предыдущий результат, поэтому они больше не закрепляют одну открытку.

Выбор происходит один раз, после успешной посадки последнего этажа и проверки устойчивости. greetingId сбрасывается при старте нового раунда. Предзагрузка и открытие финала используют уже выбранный greetingId и не проводят дополнительный розыгрыш. Запоздалый callback, пауза и повторное открытие не меняют карточку внутри одной победы.

Проверки: 91 тест в 19 файлах, TypeScript и production build успешны. Регрессии включают повторную победу для браузерного и Telegram-пользователя, совпадение предзагруженного и показанного варианта, старые ключи хранения и заблокированный localStorage. Обе исходные картинки прошли SHA-256 проверку.

В браузере два последовательных прохождения через видимые dev-контролы с настоящими падениями этажей завершились разными открытками, без ручного переключения варианта: paper-tree → reindeer. Обе картинки полностью загрузились в 1052×1494. Console errors: 0. Результаты: winter-0231-browser.json; скриншоты: screenshots/winter-0231-win-1.jpg и winter-0231-win-2.jpg.

В журнале dev остаётся предупреждение об устаревшем способе инициализации внутри rapier3d-compat/rapier_wasm3d.js:6169. Ошибкой выполнения оно не является; сторонний пакет в node_modules не изменялся.

Дизайн, модели, качество, шейдер открытки, сложность и звук в этой версии не менялись. Серверы локального запуска восстановлены: dev 5173, готовая сборка 4183. Прежний dist/0.15.0 сохранён отдельно.
